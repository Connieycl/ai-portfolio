# C路径：官方 RAG 教程对照反思

这次作业的“双线作战”经历，让我对 RAG 架构有了刻骨铭心的理解。起初，我的本机因显卡驱动冲突导致本地模型崩溃（CUDA error）；为了绕开硬件限制，我尝试将底层组件替换为云端 API，结果又因余额不足（402 报错）碰壁。最终，我回到了纯本地部署，通过强制 CPU 模式并优化环境，成功跑通了全流程。

对照 LangChain 官方教程，我深刻体会到了“组件可替换性”的意义。官方示例默认云端，而我将 Embedding 和 LLM 全都换成了本地 Ollama，并成功把英文语料替换为《HSK 等级标准》。真正的迁移不是照抄代码，而是理解数据流向。这次实战让我明白，在算力受限的真实教育场景中，如何利用开源小模型和本地库，搭建出一个防幻觉、保护隐私的学科助手。
