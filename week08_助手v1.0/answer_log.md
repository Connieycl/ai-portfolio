# 演示记录

- **运行环境**：Windows + RTX 3050 显卡
- **异常情况**：本地 Ollama 启动时触发严重的底层 CUDA 显存溢出报错（CUDA error: device kernel image is invalid）。切换云端回退后，DeepSeek 接口因余额不足（Error code: 402）拒绝请求。
