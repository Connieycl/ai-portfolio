# W8 演示记录

- **问题1**：把字句的教学难点有哪些
  - **模式**：use_rag=True，引擎：prefer="local"
  - **输出摘要**：模型给出了结构记忆、语法转换等4点，但混入了“名词性从句、虚拟语气”等英语语法。
  - **点评**：本地小模型（0.5b）能力受限导致张冠李戴，但验证了本地组装流程已完全打通。
  - 
- **问题2**：HSK4 词汇量要求是多少
  - **模式**：use_rag=True，引擎：prefer="local"
  - **输出摘要**：模型回答“通常为3000个左右。资料中未提及。”
  - **点评**：完美体现 RAG 价值！模型严格执行了“资料中未提及就如实说”的提示词，成功遏制了数字幻觉。
  - 
- **问题3**：《愚公移山》可以设计什么课堂活动
  - **模式**：use_rag=True，引擎：prefer="local"
  - **输出摘要**：生成了角色扮演、小组讨论等6点有条理的活动建议。
  - **点评**：本地模型在生成类任务上表现稳定，程序运行完美。

- **问题4**：HSK4 词汇量要求是多少
- **对比分析**：当 `use_rag=False`（纯对话）时，模型只能凭记忆，极易产生数字幻觉；当 `use_rag=True`（基于资料）时，检索资料后模型老实回答“未提及”。
- **结论**：对于需要精准数据的学科问答，开启 RAG 是必须的。
