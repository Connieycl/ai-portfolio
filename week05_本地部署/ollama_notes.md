# W5 Ollama 部署记录

## 1. 安装与拉取
- 安装方式：（离线包 / 官网安装包）
- 命令：`ollama pull qwen2.5:0.5b`

## 2. 我选的模型与理由
- 模型：qwen2.5:0.5b
- 本机内存：16GB
- 选择理由：根据"先小后大"的原则，0.5b模型体积仅有397MB，对内存要求极低，适合先跑通建立手感。若后续需要提升质量，再考虑换用4b的量化档模型。（参考"内存不足换更小量化档"的原则）

| 1 | 给《愚公移山》出HSK4阅读题 | 极快 | 差，事实错误，选项乱编 | 正常 | 优秀，切题，可直接用 | 公开资料可上云 | 云端 |

## 4. 术语正名
让大模型进小内存靠的是 **量化（Quantization）**；
**MCP** 另指"模型上下文协议"，不要混用。

## 5. 排错记录
- **显卡冲突**：在 VS Code 终端直接 `ollama run` 时，出现 `CUDA error` 导致崩溃。通过设置环境变量 `set OLLAMA_NO_CUDA=1` 强制使用 CPU 运行，成功解决。
- **代理拦截**：在写 `test_ollama.py` 时，因为机房网络有代理，代码中加入了 `s.trust_env = False`，防止请求 localhost 时被错误转发导致连接失败。
