# W5 Ollama 本地部署记录

## 1. 安装与拉取
- 安装方式：官网下载安装包
- 命令：`ollama run qwen2.5:0.5b`
- 运行现象：模型下载成功（397MB）。但在尝试运行（推理）时，终端报错 `Error: 500 ... CUDA error`。经排查，属于显卡驱动版本与 Ollama 不兼容导致，需在本机尝试通过环境变量强制使用 CPU 运行。

## 2. 我选的模型与理由
- 模型：qwen2.5:0.5b
- 本机内存：16GB
- 选择理由：根据老师提供的经验（先小后大），0.5b 模型体积仅有 397MB，对内存要求极低（4-8GB即可），适合作为本地部署的第一步尝试。建立手感后，再考虑是否下载 4b 的大模型。

## 3. 本地 vs 云端对比表（实验结论）

| 学科问题 | 本地速度 | 本地质量 | 云端速度 | 云端质量 | 隐私判断 | 该用哪个 |
|---|---|---|---|---|---|---|
| 给《愚公移山》出3道HSK4阅读题 | 极快 | 差，事实错误，出现“减轻农民负担”等胡言乱语 | 正常 | 优秀，切题，可直接用 | 公开课文，可以上云 | 云端（要质量） |
| 解释“把字句”的构成条件 | 极快 | 基本准确，但干瘪，缺例句 | 正常 | 准确，例句丰富 | 通用知识，可以上云 | 云端（要质量） |
| 批改留学生真实作文（含姓名学号） | 极快 | 能指出基本错误，不够细致 | 正常 | 批改详细，语气好 | **绝密！包含学生隐私，绝对不能上云！** | **本地（保隐私）** |

## 4. 伦理红线与排错记录
- **隐私红线**：教师对未成年人和学生数据负有保管责任，不能为了图“方便”就把包含姓名、学号、成绩的隐私数据传给云端大模型。必须坚守“不该上云的数据坚决本地化”的原则。
- **排错记录**：在运行 Python 代码连接本地模型时，由于机房网络可能配有代理，代码中特意加入了 `s.trust_env = False` 来绕过代理，防止被拦截。
