# 提示词迭代实录 (Prompt Iteration Log)

## 场景：HSK4阅读题生成 (对应模板：出题.md)

### 第1轮：初版指令（制造失控）
**我的指令**：
帮我出一套HSK阅读题。
**AI输出诊断**：
1. 难度失控：AI直接出了一套HSK6难度的题，词汇严重超纲。
2. 结构缺失：只给了题目，没有给答案和解析，无法直接使用。
**原因分析**：缺少角色设定和具体的难度约束，AI不知道我的教学对象是谁。

### 第2轮：加入角色和格式约束（初步调优）
**我的指令**：
【角色】你是国际中文教育教师。
【任务】帮我出5道HSK4阅读题。
【要求】必须以Markdown表格输出，包含题干、选项、答案。
**AI输出诊断**：
AI生成了表格，格式很好，但题型全是细节题，没有主旨题。
**原因分析**：虽然限制了格式，但没有限制题型配比。AI倾向于找最简单的细节题来凑数。

### 第3轮：加入题型配比和少样本示例（终版成型）
**我的指令**：
【角色】你是国际中文教育教师，熟悉HSK各级词汇与语法点。
【任务】为下列课文出5道HSK4阅读理解题。
【要求】
1. 每题含题干、4个选项、答案、简要解析
2. 题型配比：2细节 + 2词义 + 1主旨
3. 难度锁定HSK4，不出现超纲词
4. 以Markdown表格输出
【示例】
| 题号 | 题干 | 选项 | 答案 | 解析（含考点） |
|---|---|---|---|---|
**AI输出诊断**：
完美！生成的5道题严格符合HSK4难度，没有超纲词，而且题型完全符合2+2+1的配比，解析详细且引用了原文。
**迭代总结**：明确约束条件（配比+难度）加上少样本示例，是稳定产出高质量教学材料的钥匙。
