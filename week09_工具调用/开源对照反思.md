# C路径：smolagents 框架对照反思

通过阅读 Hugging Face 的 smolagents 文档并与我手写的 `tool_agent.py` 进行对照，我深刻体会到了“底层原理”与“框架封装”的关系。

在本次手写代码中，我们需要自己写 `SYS` 提示词去约束模型，用 `parse_calls` 写正则表达式去剥离模型多余的自然语言并抓取 JSON，还要在 `run()` 里写循环去手动执行并回喂结果。而 smolagents 框架极大地简化了这些工作：它通过 `@tool` 装饰器一键生成工具描述，底层直接调用大模型原生的 Function Calling 能力，框架自动处理了 JSON 解析与多步循环控制。

手写代码让我看透了智能体“决定-执行-回喂”的核心机制；而 smolagents 则证明了工程化框架是如何把这些复杂的脏活累活标准化封装的。先懂原理再看框架，让我不仅知道怎么用，更知道它底层到底替我省了什么。
