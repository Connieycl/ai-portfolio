# W10 预习：概念辨析与外部工具愿望

## 一、三者一句话辨析
- **Function Calling（模型侧机制）**：大模型自身的核心能力，它负责“输出意图和参数”，比如决定调用哪个工具。
- **普通 API 调用**：传统的网络请求，程序员硬编码去请求特定的接口，模型不参与决策。
- **MCP（工具侧协议）**：一种标准化的通信协议，它把各种外部工具统一封装起来，让大模型能够跨平台、标准化地“发现并调用”它们，是工具生态的接口标准。

## 二、希望 MCP 帮我接上的 2 个外部工具
1. **学校教务系统查询工具**
   - **输入**：学生姓名或学号。
   - **输出**：该学生的 HSK 考试成绩、平时作业完成情况。
2. **实时在线词典接口**
   - **输入**：中文词汇。
   - **输出**：英语/日语等多语种翻译，以及例句展示。
