# M1 会话协议草案

## 1. 事件类型与字段
包含基础字段：`session_id`（会话唯一标识）、`seq`（序列号）、`ts`（时间戳）、`type`（事件类型，如 message/tool_call）、`payload`（具体数据）。

## 2. 状态机
`idle`（空闲） → `listening`（倾听） → `thinking`（思考） → `tool_calling`（调工具） → `speaking`（输出） → 回到 `idle`。如果发生打断，直接回退到 `idle` 或 `listening`。

## 3. 权威与幂等
服务端为唯一权威数据源。由于网络问题可能导致重复发送，接收方需按 `seq` 序列号进行去重，保证操作的幂等性。

## 4. 断线语义
断线重连时，客户端带上最后一次收到的 `seq`，服务端从该 `seq` 之后补发丢失的事件，避免数据空洞。
