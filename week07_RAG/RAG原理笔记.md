# RAG 四步原理与理解

## RAG 四步：
1. **加载**：把学科文本（课文、等级标准等）读进程序。
2. **分块**：把长文本切成约 500 字的小段，相邻段重叠 50 字，避免切断语义。
3. **向量化**：把文字变成数字向量（本课用 `nomic-embed-text` 模型）。语义相近的文字，向量也相近。
4. **检索+生成**：把问题也向量化，交给向量库（Chroma）找相似度最高的 top-k 段拼进提示词，交给 `llm.ask()` 生成答案。

## 为什么检索之后答案就靠谱了？
因为模型不再“凭记忆猜”，而是“照着资料说”。向量化让“语义相近”可以被机器计算，这就是检索变可靠的关键。不训练模型、不改模型，只是给模型递上了一本参考书。
