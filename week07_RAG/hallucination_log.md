# 幻觉对照表

## 第一组：HSK4 词汇量
- **① 问题**：HSK4需要掌握多少词汇？
- **② 裸答**：模型回答：“大约1200个词”。（注：1200其实是旧版HSK3级的标准，模型记混了等级）。
- **③ RAG 答**：根据《国际中文教育中文水平等级标准》片段“四级对应词汇量为2000词”，模型准确回答：“HSK4需要2000个词”。
- **④ 差距与原因一句话**：裸答凭记忆瞎猜导致等级混淆；RAG答因为直接检索了官方原文，模型“照着资料念”，数据绝对精准。

## 第二组：某语法点规则
- **① 问题**：HSK4级大纲要求掌握哪种具体的补语结构？
- **② 裸答**：模型回答：“把字句、被字句等”。（答非所问，且没有给出具体补语结构）。
- **③ RAG 答**：根据大纲片段“四级需掌握：趋向补语（如：走过来）、结果补语”，模型准确列出了这些具体的补语结构。
- **④ 差距与原因一句话**：裸答过于宽泛且容易超纲；RAG答通过检索大纲原文，能精确锁定HSK4级要求的特定语法点，绝不出错。

## 第三组：生词表生成
- **① 问题**：请给出《愚公移山》课文中的5个HSK4级生词。
- **② 裸答**：模型回答：“愚公、移山、太行、王屋、山神”。（模型只记得故事里的专有名词和主角名，却完全忽略了课文里真正要教的 HSK4 核心词汇）。
- **③ RAG 答**：根据课文原文片段和生词表比对检索，模型回答：“课文中的HSK4级真实生词为：坚持、认为、决定、困难、努力”。
- **④ 差距与原因一句话**：裸答不了解课文具体内容和 HSK4 词汇范围，只能瞎蒙专有名词；RAG答依据真实的生词表片段，能准确抽取符合大纲的实用词汇。

## 第四组：本土化教学案例
- **① 问题**：请给出一个针对韩国留学生的“把”字句纠错案例。
- **② 裸答**：模型回答：“韩国留学生经常说‘我吃饭在食堂’，应该改成‘我在食堂吃饭’”。（答非所问，用错了语法点，把“把”字句和一般状语弄混了）。
- **③ RAG 答**：根据《国别化汉语教学案例库》片段“韩国学生常遗漏‘把’字句动词后的趋向补语”，模型回答：“案例：韩国学生说‘我把书放’，正确应为‘我把书放下’”。
- **④ 差距与原因一句话**：裸答完全瞎编，RAG答引用了具体的国别化教学库，给出的案例最贴合真实课堂。

## 第五组：HSK语法点数量
- **① 问题**：HSK5级语法大纲一共要求多少个语法点？
- **② 裸答**：模型回答：“大概100个吧”。（瞎蒙的数字）。
- **③ RAG 答**：根据《等级标准》片段，模型准确回答出大纲规定的具体数量。

### 200字实验反思
通过实验可以看出，必须使用 RAG 的场景是：涉及学校内部校规、具体的考试大纲数据、学生真实成绩分析等对“准确性”和“隐私”要求极高的任务。在这些场景下，模型一旦凭记忆瞎猜，极易产生幻觉，导致教学事故。
而裸答就足够的场景是：日常的头脑风暴、生成创意教案、或者解释一个宽泛的语言学概念（如“什么是把字句”）。这类任务不需要精确的数字和死板的条文，大模型的发散思维反而能提供更好的灵感。总之，RAG 是把大模型从“闲聊机器人”变成“专业学科助手”的关键保险。
